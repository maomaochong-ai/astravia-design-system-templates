Guidelines

Do's & Don'ts

Do — Embrace
  • Abyss (#1A1A2E) as primary background for all trading UIs
  • Kraken Purple (#7B61FF) for primary interactive elements only
  • Profit Green / Loss Red exclusively for directional price data
  • Inter Mono for all numerical data requiring alignment
  • Compact density with 4px-based spacing for dense data
  • Subtle borders (Border Dark) over heavy shadows
  • Arctic White (#FFFFFF) for all primary text
Don't — Avoid
  • Green/red for non-directional UI (buttons, links, decorations)
  • Bright saturated backgrounds outside deep navy-purple
  • Generic grays for borders — use Border Dark/Light tokens
  • Serif or decorative fonts — stick to Inter / Inter Mono
  • Overly spacious layouts that waste screen real estate
  • Kraken Purple for error/negative states
  • Hard corners on cards or buttons — keep 8-12px radius
