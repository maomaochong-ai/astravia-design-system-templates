Guidelines

Do's & Don'ts

Do — Embrace
  • Obsidian (#1C1C1E) as primary background
  • Cloud (#EBEBF5) for all primary text
  • Coral Red (#FF6363) for accent & active states
  • 8px radius as default for all interactive elements
  • Charcoal (#38383A) for all borders and dividers
  • Inter Mono for keyboard shortcuts and code
  • Compact spacing with 8px element gaps
Don't — Avoid
  • Bright saturated backgrounds
  • Coral Red for text — use for backgrounds/borders
  • Hard sharp corners on interactive elements
  • Heavy drop shadows — use surface colors
  • Dense text blocks without padding
  • Font families outside Inter / Inter Mono
  • Coral Red for decorative-only elements
