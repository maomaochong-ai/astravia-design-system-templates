Making life multiplanetary.

An inspired interpretation of Spasex's design language — a mission-oriented aerospace brand built on pure black canvas, full-bleed photographic and video heroes of rockets and Mars landscapes, and uppercase D-DIN display type set in tight vertical leading. UI chrome is intentionally minimal a single ghost outlined pill button per band, all-caps eyebrow…

06 / Guidelines

Keep it recognizable.

Concrete implementation guardrails for preserving the visual character of SpaceX.

Do / Embrace

  • Use pure black as the primary canvas.
  • Set mission headlines in uppercase condensed type.
  • Keep UI chrome minimal over immersive imagery.
  • Use one outlined action per major visual band.

Don't / Avoid

  • Do not add ornamental color to navigation.
  • Do not use soft pastel cards on the black canvas.
  • Do not over-round controls beyond the documented pill.
  • Do not let UI decoration compete with mission imagery.
