Guidelines

Do's & Don'ts

Do — Embrace
  • Void Black (#000000) as the primary canvas
  • PlayStation Blue (#003791) for all primary CTAs
  • Pure White (#ffffff) for all primary text
  • Uppercase with wide letter-spacing on buttons
  • Sharp corners (0px) on game artwork
  • Spacious layout with 32px+ section gaps
  • Trophy Gold only for achievement UI
  • PS Plus Red only for PS Plus tiers
Don't — Avoid
  • Colored backgrounds behind game artwork
  • PlayStation Blue for decorative elements
  • Soft rounded corners on game cards
  • Mixing Trophy Gold with PS Plus Red
  • Dense packing without breathing room
  • Cool Gray or Muted Gray for interactive elements
  • Colored text on colored backgrounds
  • Heavy drop shadows — use subtle brightness shifts
