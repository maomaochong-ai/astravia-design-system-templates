Guidelines

Do's & Don'ts

Do — Embrace
  • Charcoal (#1D1D1D) as default page background
  • Hedgehog Green (#1DB954) for primary CTAs and success
  • Blaze Orange (#F54E00) sparingly for accent punch
  • JetBrains Mono for all metrics, code, and data
  • 4px-based spacing with 12px element gaps
  • 12px radius for cards, 6px for buttons
  • Let green/orange duo create visual rhythm
Don't — Avoid
  • Orange for surfaces larger than buttons/tags
  • Bright saturated backgrounds
  • Serif or decorative fonts
  • Hard 0px corners on interactive elements
  • Generic blue (#0000FF) for links
  • Green and orange in the same element
  • Dense packing without breathing room
