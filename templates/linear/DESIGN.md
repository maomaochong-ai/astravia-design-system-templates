# Linear — Style Reference

> **Theme:** dark — **Voice:** midnight precision instrument

Linear uses Void #08090a, hairline Graphite geometry, Paper type and one Acid Lime #e4f222 action signal. Typography stays within 400–590; product UI is the visual texture.

## Components

- Primary: Acid Lime, Void text, 6px radius, 10px — 16px.
- Ghost: transparent, Graphite border, Mist text, 6px radius.
- Product frame: Carbon, 12px radius, subtle inset border, 24px padding.
- Input: 6px radius; focus border brightens to Mist.

Use Acid Lime once per view. Separate surfaces with hairline Graphite, not decorative shadows.
